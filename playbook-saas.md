# Playbook: SaaS site

Tuning the full GEO checklist for a SaaS product site. Adjust priorities, not the whole checklist.

## Highest-impact items

1. **SoftwareApplication schema on every product page.** AI engines categorize you correctly only with this.
2. **Pricing page citability.** This is the page AI engines quote most. Aim for 80+ on the citability scorer.
3. **Founder Person schema with strong sameAs.** Solo founders win on E-E-A-T when their identity is portable across LinkedIn, GitHub, Twitter, podcasts.
4. **Comparison pages ("X vs Y").** Build one for every serious competitor. AI engines surface these for "X alternative" queries.
5. **llms.txt that lists pricing, docs, comparison pages, founder page.**

## Lower priority for SaaS

- Local business schema (skip)
- Recipe schema (skip)
- Event schema (skip unless you run webinars regularly)

## SaaS-specific paragraphs to audit

- Homepage hero subtitle: must be a concrete claim with a number or named outcome
- Pricing tier descriptions: each tier needs 1 to 2 sentences of self-contained explanation
- "Why us" sections: replace adjective stacks with specific differences from competitors
- Changelog entries: each entry is its own citable passage; date it, name the feature

## SaaS-specific E-E-A-T moves

- Public roadmap with named contributors
- Customer logos with named case studies linked
- Founder writes monthly under their own byline
- Open-source any tooling you can; AI engines weight GitHub presence

## Common SaaS mistakes

- Homepage is a hero image with three feature cards. Zero citable text.
- Pricing page is a comparison table only. No prose for AI to extract.
- "About" page is a stock photo grid. No bios, no Person schema.
- Documentation is search-only; no navigable structure for AI bots.
